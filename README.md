React-приложение с авторизацией на архитектуре Feature-Sliced Design: регистрация, вход, профиль, выход и защищённые маршруты. JWT access-токен хранится в Redux, refresh-токен — в HttpOnly cookie. Реализованы восстановление сессии и автоматическое обновление токена.

Стек: Vite, React, TypeScript, Redux Toolkit, RTK Query, React Router DOM, React Hook Form, CSS Modules.
